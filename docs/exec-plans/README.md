# 실행 계획

여러 세션 또는 설계·검증·외부 변경이 필요한 작업은 [TEMPLATE.md](TEMPLATE.md)를 복사해 `active/번호-slug.md`로 기록한다. 단순 수정은 이슈·PR에 같은 핵심 정보를 남겨도 된다.

활성 계획은 현재 목표·완료한 일·남은 일·검증·다음 행동의 원본이다. 대화가 끊기면 Git 상태와 계획을 함께 읽고 재검증한다. 완료는 수락 기준을 실제로 충족한 뒤 `completed/`로 이동한다. `.gitkeep`은 비어 있는 디렉터리를 Git에 보존하기 위한 파일이다.

계획 상태와 배포 상태는 다르다. 최초 베이스 작성 완료가 제품 출시를 뜻하지 않는다. 계획에 비밀이나 개인정보를 넣지 않고 필요한 로그는 정리된 링크로 연결한다.
