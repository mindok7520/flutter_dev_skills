# 설계 결정 기록

"ADR"은 Architecture Decision Record, 중요한 설계 선택의 맥락·대안·결과를 남기는 기록이다. 상태관리·데이터 저장·인증·광고·결제 공급자·플랫폼 범위·호환성을 바꾸는 결정을 기록한다. 단순 파일명 수정마다 만들지 않는다.

`ADR_TEMPLATE.md`를 복사해 `0001-short-title.md`처럼 번호를 부여한다. 상태는 proposed·accepted·superseded·rejected 중 하나로 둔다. 승인자는 실제 담당자이고 AI가 임의로 타인의 승인을 기록하지 않는다. 이전 결정을 바꾸면 원문을 지우지 않고 새 ADR과 연결한다.

선택은 측정·요구·위험에 근거한다. 인기나 익숙함만으로 의존성을 채택하지 않는다. 관련 이슈·실행 계획·변경 PR·검증 증거를 연결한다.
