# 원본 요구 목록과 최종 배치

초기 제안은 앱 프로젝트까지 포함한 목록이었다. 최종 범위는 **새 프로젝트에 복사할 개발 자료 저장소**다. 따라서 명시된 문서·프롬프트·스킬·양식은 모두 작성하고, 실행 앱에만 필요한 설정·도구·워크플로는 템플릿으로 분리했다.

| 원래 제안한 위치 | 최종 위치 | 이유 |
| --- | --- | --- |
| 루트 지침·개발 문서·프롬프트·스킬 | 같은 경로 | 공통 자료의 원본 |
| `pubspec.yaml`, 분석·국제화·테스트·SDK·환경 예시 | `templates/flutter/` | 대상 프로젝트의 기존 파일에 선택적으로 통합 |
| `tool/*.dart` | `templates/flutter/tool/` | 대상 Flutter 앱에서 실행하는 개발 도구 |
| Android·iOS·Web·앱 release 워크플로 | `templates/flutter/.github/workflows/` | 제품별 도구 체인·서명·증거가 필요한 예시 |
| 자료 저장소의 CI·의존성·정기 점검 | `.github/workflows/` | 앱을 빌드하지 않고 자료를 검사 |
| `scripts/bootstrap.*`, `verify.*` | `scripts/` 및 대상용 `templates/flutter/scripts/` | 자료 도입·자료 검증과 앱 개발 도구를 분리 |
| 앱 `lib/`, `test/`, `integration_test/`, `assets/`, 플랫폼 폴더 | 포함하지 않음 | 대상 프로젝트에서 제품 요구에 따라 생성 |

처음 명시된 **297개 파일**의 대응 경로는 [파일 검증 목록](../config/required_files.json)에 기록한다. 원본의 `.github/prompts/`는 파일명을 생략한 디렉터리였으므로 공통 프롬프트 54개에 대응하는 실제 `.prompt.md` 어댑터를 추가했다. 스킬의 UI 메타데이터·도입 도구·자료 검증·템플릿 안내도 필요한 구성으로 추가했다.

이 목록은 원본 질문·답변을 보관하기 위한 파일이 아니라 누락 검증의 기준이다. 원본 질문·답변 텍스트는 초기화 완료 시 저장소에서 제거한다.
