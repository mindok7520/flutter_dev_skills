# 제품 정의

이 파일은 새 프로젝트의 제품 결정을 기록하는 양식이다. 앱 구현 전에 실제 이슈와 조사 결과를 바탕으로 채운다. 미정 값은 임의로 확정하지 말고 결정할 담당자·이슈·시점을 적는다.

## 제품 목표

해결할 문제, 대상 사용자, 기존 대안, 핵심 사용자 가치와 성공 지표를 작성한다. 개발 기반과 제품 기능을 구분한다.

## 범위

최초 출시 플랫폼·국가·언어·연령·핵심 흐름·포함/제외 기능을 기록한다. 지원할 OS·브라우저는 실제 도구 체인과 의존성으로 검증한다.

## 현재 상태

구현된 기능·검증한 플랫폼·미구현 기능·알려진 제한을 실제 코드와 테스트에 근거해 적는다. 템플릿 도입을 기능 구현으로 표시하지 않는다.

## 기술 결정

실제 SDK·잠금 파일·상태관리·라우터·서버·저장소의 선택과 관련 ADR을 연결한다. 기존 코드가 있다면 그 구조를 먼저 조사한다.

## 데이터와 수익화

처리 데이터·인증·동의·보관·삭제·광고·상품·결제 공급자·서버 검증·권리 복원을 기록한다. 채택하지 않은 SDK는 설치하지 않는다.

## 품질과 출시

대표 기기·성능 목표·접근성·테스트 명령·보안 검증·서명·운영 담당자·복구 절차를 작성한다. 계획·이슈·릴리스 증거의 경로를 연결한다.

## 다음 작업

우선 이슈·수락 기준·작업 브랜치·실행 계획과 다음 구체 행동을 기록한다. 공통 정책은 `docs/README.md`에서 필요한 분야만 읽는다.
