# 보안 보고

보안 결함의 민감한 재현·비밀·개인정보를 공개 이슈에 게시하지 않는다. 대상 저장소의 비공개 보안 보고 기능 또는 제품이 지정한 보안 연락 경로를 사용한다. 아직 경로가 없으면 상세 내용 없이 비공개 연락 경로를 요청한다.

제품 책임자는 출시 전에 보고 채널·지원 버전·응답 목표·담당자를 확정한다. 검증되지 않은 연락처와 지원 약정을 임의로 작성하지 않는다.

보고에는 영향 버전·플랫폼·최소 재현·실제/기대 결과·민감정보를 제거한 증거를 포함한다. 대응은 `docs/security/INCIDENT_RESPONSE.md`, 설계와 검증은 `docs/security/SECURITY_ARCHITECTURE.md` 및 `docs/security/SECURITY_TESTING.md`를 따른다.
