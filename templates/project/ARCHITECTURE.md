# 제품 아키텍처

이 문서는 실제 대상 프로젝트를 조사한 뒤 채우는 설계 지도다. 자료 저장소의 폴더가 앱 구현을 대신하지 않는다.

## 현재 구조

앱 진입점·화면·상태·데이터·플랫폼·서버 경로를 실제 파일에 연결한다. 새 프로젝트라면 필요한 최소 수직 기능부터 설계한다.

## 의존성과 소유권

UI·ViewModel·저장소·서비스 경계를 정의하고 객체 생성·해제 주체를 기록한다. 불필요한 도메인 계층과 전역 가변 상태를 추가하지 않는다. 기본안은 `docs/architecture/APP_ARCHITECTURE.md`를 참고한다.

## 외부 경계

네트워크·인증·결제·광고·저장소·분석의 신뢰 경계, 입력 검증, 실패·취소·타임아웃·복구를 기록한다. 클라이언트 권한을 서버가 신뢰하지 않게 한다.

## 플랫폼·품질

공유 코드와 플랫폼 어댑터, 웹·모바일 차이, 지원 행렬, 테스트 계층, 성능 측정과 관측 지점을 적는다.

## 결정과 변화

선택한 아키텍처의 이유·대안·비용·제약을 ADR에 연결한다. 코드와 달라졌을 때 이 문서를 같은 변경에서 갱신한다.
